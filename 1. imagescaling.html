Collaborative Practice 1: Aspect Ratio and Object Fit

Goal: control the shape of an image area with aspect-ratio, then decide how the image should fit inside that area with object-fit.

1. Read First

  • MDN: aspect-ratio
  • MDN: object-fit
  • MDN: object-position

Partner check: explain the difference between changing an image's container shape and changing how the image fills that container.

2. Work Roles

Driver
Edits the CSS one property at a time.
Navigator
Reads the reference links and predicts what should happen.
Tester
Refreshes the page and describes what changed visually.

3. Compare Examples

Square + cover

cover fills the whole square and may crop part of the image.

Wide + contain

contain keeps the whole image visible and may leave empty space.

Tall + fill

fill forces the image into the box and can distort it.

4. Hands-On Practice

Work together in the CSS TODO area. Use the values below to reach each final goal. Change one value at a time, refresh, and explain why your choice works.

Value Bank

  • aspect-ratio: 1 / 1, 16 / 9, 3 / 4
  • object-fit: cover, contain, fill, none, scale-down
  • object-position: center, top, bottom, 50% 30%

Final Goals

  1. Create a square profile photo that fills the frame without stretching.
  2. Create a wide banner image that fills the full width and keeps the main subject visible.
  3. Create a preview image where the entire original image is visible, even if empty space appears.
  4. Create a tall story-card image and move the visible focus point to the most important part.
